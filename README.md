# DevSecOps Flask Project

## Project

Simple Flask application for learning DevSecOps.

## Requirements

- Python 3.11+
- pip

## Create Virtual Environment

```bash
python -m venv venv
```

### Activate

Windows

```bash
venv\Scripts\activate
```

Linux/Mac

```bash
source venv/bin/activate
```

## Install Packages

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

## Open Browser

```
http://localhost:5000
```

## Health Check

```
http://localhost:5000/health
```
